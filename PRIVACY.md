# Privacy Policy

PromptPulse is a local demo app for analyzing Prompted-style post drafts.

## Manual Paste / Import

Users control what they paste. PromptPulse v1 only analyzes text manually entered by the user.

## Local Demo Data

PromptPulse includes local JSON demo data inspired by Prompted-style builder posts. It does not fetch live Prompted data.

## No Login

PromptPulse does not require a login.

## No Analytics by Default

PromptPulse does not include analytics tracking by default.

## No Cookies by Default

PromptPulse does not set cookies by default.

## No Data Upload in v1

PromptPulse has no backend in v1. Pasted drafts are not uploaded to a server.

## No Prompted Account Access

PromptPulse does not access Prompted accounts, cookies, browser storage, sessions, private APIs, or hidden endpoints.

## Independent Demo

PromptPulse is an independent demo project inspired by Prompted builder workflows. It is not officially affiliated with Prompted unless the Prompted team chooses to adopt or integrate it.
